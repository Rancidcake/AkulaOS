# AkulaOS

> Fast. Stable. Visible. An Arch-based Linux remix for machines that should still matter.

**Akula** (Акула, "shark") is a minimal, constructivist-themed Linux distribution
built on Arch Linux + Sway. Inspired structurally by Omarchy, redesigned for
older hardware and quieter aesthetics.

## Philosophy

1. **Fast first.** If a feature costs more than 50MB of RAM, it must justify itself.
2. **Stable second.** Curated package set. No bleeding-edge for its own sake.
3. **Visible third.** Bold typography, hairline rules, two backgrounds + one accent.
   Designed once, applied everywhere.

## Status

Pre-alpha. Not yet installable. Watch this space.

## Target hardware

- 4 GB RAM minimum (idle target: under 800 MB)
- Intel i3/i5 (any generation) or equivalent AMD
- UEFI or BIOS boot
- 30 GB disk minimum
